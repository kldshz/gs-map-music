## 页面与互动验收

1. 桌面 1440×900 地图占主区域，侧面音乐面板、顶部导航/搜索/昼夜入口、底部常驻播放器；390×844 竖屏顺畅滚动，地图仍显著，面板可达，播放器不挡内容、无横向溢出。移动端亦提供搜索与路线入口。
2. 大图清楚显示 A/B/C 的示例地点（数据坐标 100/500/900，y=384，图1024×768）和区域；HTML 按钮或可键盘操作的地图点。可以在SVG中画原创合成地貌，不加载真实瓦片；区域信息、图例和合成标注可见。
3. 选点、昼夜切换、示例列表和空区域 C可浏览；只作为样本预览，不是阶段3真实数据验收。用户能查看原神目录条目及其无音源、pending/unknown、作曲家未知等状态。细节不要错误显示12秒片段为原作品时长。
4. 搜索是当前少量示例的界面预览，支持标题等已有文字并提供空结果；可选择结果进入音乐信息。对有坐标关联展示定位示例的入口，对无坐标条目明确待核实不假定位。不得宣称旋律识别。
5. 播放器显示选中曲目、状态、上一/下一、播放、进度、音量、队列/随机/循环的未来入口。本阶段尚未实现播放引擎：真正播放/进度/音量等按钮禁用或给出“阶段4接入”，绝不使用假计时器、isPlaying=true、假的声波或音源成功状态。可选择曲目预览元数据；实际音源与浏览器发声验收阶段4。
6. 路线面板提供绘制模式、节点清单、撤销/清除、速度输入、开始/暂停的入口。允许点击已有示例点组成路线草稿并画线（只用样本点），键盘也能添加；不要实现生产任意点编辑、模拟时间/移动或按区切歌。开始/暂停不可宣称真实运行，应禁用且说明阶段5接入；静态起点标记和路线草稿清楚区分。
7. 收藏、个人列表、简介编辑、本地导入只做有反馈的入口（阶段4），不实现持久化。地图加载/失败、音频不可用、空曲库/搜索等反馈区域和入口清楚，不常驻大量开发术语；“阶段2示例”说明集中表达，关键曲目状态就地显示。
8. 可访问性：语义按钮/label、标题层级、焦点可见、图标按钮aria-label、Esc关闭浮层，避免全局监听劫持输入。跳过导航至主内容。无悬空导航与死链接；暂未接入的功能有禁用说明。动画遵守 prefers-reduced-motion。
9. 在界面来源/资源说明中展示 Kevin MacLeod、incompetech.com、CC BY 4.0 链接、开头0–12秒剪辑说明，明显说明不是原神 OST。真实目录来源链接可从 sources 读取。合成地图不是实际游戏地图。
