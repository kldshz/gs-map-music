# 网易公开外链接入与真实音频补验（2026-10-08，阶段4）

用户引用NetStart文档的独立外链方案：`https://music.163.com/song/media/outer/url?id=<网易数字ID>.mp3`直接作为Audio.src。此前仅测NetStart托管song/url接口，没有测试外链；该接口404及官方开发者应用visible=false不能推导网易公开媒体入口不可用。本轮实际补测后接入。

## 接入

只读现有MySQL中的网易数字ID；本机匹配文件优先，没有则无凭据HEAD探测固定HTTPS网易外链，跟随媒体重定向核实HTTP成功、audio类型及music.126.net域。超时10秒/成功缓存60秒/失败30秒/同曲请求合并。播放器拿到稳定ID入口作为Audio.src，网易自行重定向，临时CDN地址不返回、不保存、不入库。没有发送appid/privateKey/官方CLI登录令牌到第三方；不依赖CLI应用歌曲权限，不调用其play/队列，不使用NetStart托管服务。

资源provider=netease-outer，preview=null（缺明确试听字段），expiresAt=null（稳定入口没有报告期限，不表示CDN链接永久有效）。只有真实媒体playing/timeupdate确认播放与进度。403/404、HTML、无资源、网络/解码错误仍诚实反馈，可点击重试，不找同名替代音乐。只调整Codex负责的播放/接口逻辑与状态文字，没有改布局设计，不追加Claude调用，沿用C4-01交付。

- 5173实际页面《晨曦酒庄》：media.paused=false，readyState=4，error=null，时间正常增长；实看播放46秒/总长1:08的截图.local/browser-tests/stage4-outer-playing.jpg。截图后主动暂停测试播放，页面可继续操作。
- 生产preview Edge真实媒体时长68.321229秒、50.138896秒，分别与目录68/50秒相符。不是测试合成音频或非原神替代；按现有官方元数据的数字ID请求。
- 真实播放/暂停、15秒拖动、音量0.25、上下首、两首队列随机及历史上一首、单曲循环、队尾列表循环、切地图/点位面板与收起面板连续、刷新不自动发声、点击重新解析后从10秒恢复全部通过。循环由UI拖至最后整数秒触发真实ended事件，不派发模拟结束。
- 内存解码晨曦酒庄的实际HTTP音频：68.321224秒，采样平方和640.1416>0；验证非静音可解码，不保存音频文件。证据JSON仅.local/browser-tests/stage4-real-audio-result.json，截图stage4-real-audio.png。
- 类型/构建及62数据业务测试通过；本轮7项针对性生产UI全部通过，其中真实音频测试不再skip。此前25生产UI/2开发编辑回归保持历史，未冒称本轮重新全跑。初次真实循环用默认step=1滑条填写小数被浏览器拒绝，修正测试为整数秒后通过，非循环产品失败。
