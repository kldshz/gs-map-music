# 跨区域路线测试方案

2026-10-07更新：昼夜已取消。路线编辑、模拟移动和自动切歌在阶段5实现。阶段3只有真实地图/点位/分层标签，没有真实区域多边形，也未实现路线；旧合成三区/非原神音源已从当前产品移除。

## 空间与选曲规则

所有路线节点使用canonical图像坐标，速度为图像单位/秒。地图缩放不能改变路径；独立mapId/地下层之间不自动连线。国家/地区目录和锚点标签不产生区域边界。阶段5先选择并记录判区方法：有可信多边形可用point-in-polygon；否则可采用明确标注的近邻锚点影响范围或用户补充边界。范围/半径/重叠优先级须以实际数据验证，不能宣称复刻游戏音乐逻辑。

候选曲需有verified关系和有效原神音源，pending或无坐标/无音源不参加自动选择。不做昼夜筛选。有至少两首时回避上一首；单曲重复进入保持当前进度；进入空库让当前曲播完后暂停，移动继续并显示空态。用户主动暂停不因跨区自动恢复；手动选曲退出自动模式，手动队列保留。

边界稳定初始500ms、进入8图像单位、过渡0.8s仅为历史候选参数，阶段5按实际空间/速度实测再定。高速短暂经过需记录，避免每帧重启音乐；中途改路线暂停并取消过期请求。没有可用音源时不伪造切歌或过渡成功。

## 必测案例

| ID | 操作/条件 | 验收证据 |
| --- | --- | --- |
| R01 | 同瓦片集选3个不同地区A→B→C→B→A；用真实已补点位及可审查判区规则 | 记录模拟时钟/坐标/候选与稳定地区/曲目ID/切换原因，空音乐数据时先仅验路径 |
| R02 | 多曲随机、单曲重复进入 | 固定随机序列避免连续重复；同曲不重置进度 |
| R03 | 进入空库 | 反馈空库、当前曲结束暂停，移动继续，无假音源 |
| R04 | 共享边反复跨越后深入新区 | 防抖且最终一次有效切换，记录阈值与实测 |
| R05 | 速度50/200/2000及后台标签页恢复 | 位置插值一致，短暂经过有记录，不在恢复后一帧跳完整路线 |
| R06 | 连续快速换曲/修改关联候选 | 最新请求生效、旧音源请求不覆盖当前；不包含昼夜操作 |
| R07 | 暂停恢复/改速/改节点/撤销清除 | 主动暂停不自动恢复，改速保位置，不足两点禁用开始 |
| R08 | 手动队列/自动路线切换 | 模式与队列明确，手动播放不被后台抢走 |
| R09 | 延迟/过期URL/404/解码/权限或手势拒绝 | 真实错误、取消旧请求、释放objectURL，无假播放成功 |
| R10 | 多层/重叠/图外/无坐标/未知关联 | 空间隔离与排序确定；pending不可自动选曲 |
| R11 | 过渡/曲终/音量0或1 | 实际发声与时间/音量检查，失败回退，不以静态UI证明 |
| R12 | 拖动缩放/手机/键盘路线编辑 | 坐标不变、标记贴合，撤销/清除/暂停可达且焦点恢复 |

阶段3的配置往返、点位高亮与分层测试只证明地图基础，不是上述路线移动或音频调度通过。全部R01–R12仍待阶段5。
