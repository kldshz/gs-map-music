# 跨区域路线测试方案

这里只定义期望和必要数学探针，生产路线编辑、移动与调度在阶段 5 实现。真实地图边界尚无授权资源；测试合成三区不宣称复刻游戏逻辑。数据见 [route-fixtures.json](../data/route-fixtures.json) 与 [接口](../src/domain/contracts.ts)。

## 区域和调度规则

同一 mapId/surfaceId 的区域先做 point-in-polygon，孔洞不包含在内；重叠依次按 priority 高、外环面积小、ID 字典序选择。共享边明确包含，按同一排序决定，保证结果可重复。没有几何的地点不参加空间判定。真实区域若来自手工近似，显示版本、来源和精度限制。

生产方案先取候选区域，再确认稳定候选：初选连续 500ms、距边界进入至少 8 图像单位；具体值在阶段 5 根据真实缩放/速度测试调整，属于待实测参数。边界持续抖动时保留原区；暂停不推进候选计时。高速可能不足 500ms 穿过小区域：通过线段与区域交点识别经过记录，保留最后稳定区域的音乐，提示短暂经过并在停留后确认，避免一帧跳过完全不记录。不保证所有短停留都切歌。

可选曲必须具备当前 day/night 或 any 的关联、有效音源以及 verified 证据；标注的示例模式额外允许 synthetic。unknown/pending 排除。有至少两首时去除上一首再随机，测试使用固定随机序列；只有一首且当前正在播该首则保持，不重置进度。曲终后的循环由已选择循环模式决定。

进入空库不启动假音源：上一首播至结束，再暂停，区域面板显示空曲库，模拟移动继续；随后进入有曲区自动恢复需有已获用户手势且用户没有主动暂停。手动选曲会退出路线自动选曲，路线可继续移动；手动队列保留。返回路线播放后从当前位置选曲。用户主动暂停后跨区不自动恢复，开始路线不应绕过浏览器手势限制。

切换昼夜触发重新计算当前稳定区域，不等待跨区；播放请求用版本号取消过期结果。双通道过渡目标初选 0.8s，在阶段 5 验证峰值音量/结束事件/失败回退后决定；当前没有生产实现。中途改路线先暂停模拟并取消旧候选/请求，更新后从新起点开始；撤销到不足 2 点不能开始。速度改变保留位置，不改变曲目进度。

## 数据基线

图像 1024×768，A 为 x=0..340，B 为 x=340..680，C 为 x=680..1024；共享边按上述规则。路线 `(100,384)→(500,384)→(900,384)→(500,384)→(100,384)` 的区域序列为 **A→B→C→B→A**；速度单位为图像单位/秒。

| 时段 | A 可选 | B 可选 | C |
| --- | --- | --- | --- |
| 白天 | Carefree、Brittle Rille | Carefree | 空 |
| 夜晚 | Brittle Rille | Brittle Rille | 空 |

其中所有地点和时段都是合成分配，曲目均为许可非原神音乐；真实 OST 候选不参加选曲。元数据原长度与 12 秒演示片段明确区分。

## 阶段 5 必测案例

| ID | 操作 / 条件 | 期望与取证 |
| --- | --- | --- |
| R01 | 白天/夜晚跑完整 A→B→C→B→A | 记录模拟时间、位置、候选/稳定区域、可选 ID、当前曲和切换原因；筛选与上表一致 |
| R02 | A 白天两曲连续选择 | 固定随机种子下不连续重复；B 单曲重复进入不重新启动正在播放的同曲 |
| R03 | 进入 C，无曲目 | 显示空库；当前曲至结束后暂停；移动继续；不伪造播放状态 |
| R04 | x=340 附近反复±2 单位、再进入 B 内部 | 不反复切歌；满足稳定时间/距离后一次切换，记录时间阈值 |
| R05 | 速度 50/200/2000，窗口暂停与大帧间隔 | 移动按模拟时钟插值；短区域记录经过并按稳定策略处理，无频繁音频重启；标签页恢复不突然跨越整条路线 |
| R06 | 正在播放时切换昼夜、快速连续操作 | 立即按当前区域重选；过期请求不会覆盖最新选择；只有一首保持进度 |
| R07 | 暂停/恢复、改速度、中途移节点/撤销/清除 | 主动暂停不自动恢复；速度改动保位置；改路线按定义重置；无有效路线禁止开始 |
| R08 | 手动选曲、手动队列，再返回路线模式 | 模式清晰，队列保留；手动选择不被后台路线抢走，重新进入按当前位置选曲 |
| R09 | 音频延迟/404/解码失败/手势拒绝 | 真实错误反馈，无假成功；继续定位；切曲错误不残留双通道或旧 object URL |
| R10 | 重叠、多层、孔洞、地图外、未知位置 | 同空间确定排序；孔洞/图外无区域；拒绝跨层路线；unknown/pending 不参加自动选择 |
| R11 | 连续 0.8s 过渡、片段结束、音量 0/1 | 实测音量与进度，不出现叠加过响；失败后串行回退有说明；过渡参数以结果修订 |
| R12 | 地图缩放拖动、移动端、键盘修改路线 | 内部坐标不改变，标记贴合；入口可用，键盘能撤销、清除及暂停，焦点不丢失 |

阶段 1 的 `node scripts/check-stage1.mjs` 仅实际验证 R01 的几何序列/候选库和 R10 的基础重叠/孔洞/空间隔离，以及坐标与音频文件。R02–R09、R11–R12 与实际浏览器路线播放仍未开始；不得把静态期望当作实现测试通过。
