# 阶段4播放器与边栏返修

2026-10-08；仍在阶段4。本轮不调整曲库、地理分类、点位关联和路线。

## 产品与分工

Codex负责左右栏业务状态、收藏交集筛选、歌单操作、开发编辑门控与播放/存储整合；实际本机Claude Opus 5-5/high负责播放器、左右栏、SVG图标、提示、动画与布局。两份工单通过现有stdin runner调用，模型工具禁用，Codex审核文件白名单后落盘；模型配置与返回核实见COLLABORATION及工单结果。

播放列表即本地歌单：左栏提供创建、选中、搜索、播放、排序、重命名和移除。歌曲卡片发起添加时携带该曲ID；创建成功可直接加入，保存失败保留待添加歌曲和草稿。收藏索引与右栏文字/专辑/地区筛选相交；搜索和点位曲库均显示收藏星标。

播放器常驻App，布局变化不卸载媒体；普通播放状态使用图标与按钮状态，不显示音源提供者，实际播放错误与存储错误继续反馈。各曲卡片包含自己的播放/队列/收藏/歌单操作，明确操作对象。

单曲信息只保留基本信息和关联点位，原完整元数据并入基本信息。个人评价UI及检索撤下，历史评价字段与浏览器存储保留；不清理用户数据。独立曲目说明/元数据来源折叠区、音乐库导入导出入口撤下。开发环境也默认关闭关联编辑；只有主动开启且服务可用才显示增删/恢复，生产没有此入口。

## 数据与同步边界

收藏、歌单仍使用原localStorage格式，只保存ID，不写网易账号、MySQL或项目曲库。开发关联记录继续写既有审核文件，不自动同步数据库；本轮不改1663曲/13038条pending关系、884点位/62神像、人工关联和评价数据。网易公开外链播放适配、数字ID与主键前缀不变。pending仍不参与路线选曲。

验收结果与实际页面检查完成后记入本文件及ACCEPTANCE。外部音源/瓦片服务的长期可用性及公网HTTPS部署继续按既有边界处理。
