# NetStart音乐API可用性核实（2026-10-08，阶段4）

追加：用户提醒文档中的独立网易media/outer/url入口，经实测两首原神音频可播放且已接入。此处NetStart托管API的404结论不覆盖网易公开外链；最新验收见[NETEASE_OUTER_REVIEW](NETEASE_OUTER_REVIEW.md)，历史阻塞描述仅限当时已测路径。

用户提出使用 https://apis.netstart.cn/music/#/?id=获取音乐-url 。本轮实际读取站点HTML及其Docsify README.md，未读取或发送本机网易凭据、账号cookie、appId/privateKey。

## 文档事实

- 提供`/song/url?id=数字ID&br=码率`，支持逗号分隔多个ID；`/check/music`用于可用性检查。
- 文档说明未登录或非会员可能返回试听片段，并提示URL可能403。URL是否存在、完整音频与浏览器能否播放须分别验证。
- README“工作原理”自述“跨站请求伪造 (CSRF), 伪造请求头 , 调用官方 API”。这是第三方接口服务，不是此前配置应用的网易官方开放平台，也没有在所读文档中取得音乐素材使用授权或服务可用性保证。接口名称不能作为官方授权证据。

## 实际请求

| 请求（不带账号或认证） | 响应 |
| --- | --- |
| `/music/`与`/music/README.md` | 文档可读取 |
| `/music/song/url?id=1455706951,1455706952&br=128000` | HTTP404，`{"code":404,"data":null,"msg":"Not Found"}` |
| `/music/song/url?id=1455706951&br=128000` | HTTP404，相同Not Found，没有音频URL |
| `/music/check/music?id=1455706951&br=128000` | HTTP404，`{"success":false,"message":"亲爱的,暂无版权"}` |

1455706951/1455706952为既有曲库与MySQL的《晨曦酒庄》/《孤独的旅居》网易ID。仅用这些原神歌曲作小规模只读探针，不搜同名替代或测试付费绕过。原始文档、响应及头部留.local/research/netstart-*。

上述只能证明本次原神样本请求没有取得可播放资源，不能据此宣称所有歌曲/所有接口永久失效。没有实际音源可供解码或发声测试。

## 决定

当前不替换现有后端，不加入默认必失败的第三方适配器；不把第三方登录当必要补救，不向该站发送已有平台凭据。阶段4原神真实音频验收继续阻塞。未来若服务恢复并实际返回对应原神URL，再核实试听字段/过期时间/浏览器播放与服务使用条件后，可在现有PlaybackResource适配层接入；本轮未承诺可用，也未实现新的音源回退或修改播放UI。
