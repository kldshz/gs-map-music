# 个人本地资源

原神音频建议存放于 `resources/local/audio/genshin/`，本机已创建该目录。`resources/local/` 全部被 Git 忽略；原神音频不进入 public、仓库或网站发行包。

先准备一张专辑中的几首曲目即可，不需要一次下载全 OST。使用自己可合法获取并用于个人播放的 MP3、FLAC、WAV，也可按浏览器支持情况使用 OGG/M4A。MVP 不支持 `.ncm`，不实现音乐平台登录、爬取、签名接口或加密格式解码。

阶段4本机服务直接读取该目录：用对应网易数字歌曲ID命名，如 `1455706951.mp3`（晨曦酒庄）与 `1455706952.mp3`（孤独的旅居）。只服务当前原神曲库且MySQL中存在的歌曲，不根据同名曲猜测替换。扩展名支持小写mp3/flac/wav/ogg/m4a，实际解码依浏览器；不要将剪辑版误配到完整曲目。歌曲元数据、作曲家和地点仍来自现有来源，不由文件名生成。

运行 `npm run dev` 或 `npm run preview`，播放时读取MySQL稳定ID并动态解析；本机文件用同源HTTP Range流提供，支持进度拖动。音频不复制到浏览器存储、不导出/下载、不入Git。刷新恢复当前曲目、队列、位置、音量、随机/循环及收藏/列表，等待用户点击播放，重新核实文件。纯静态部署没有本机资源服务；未找到音频时显示失败，不假播放。

旧非原神示例已经移除，当前禁止用其替代。网易个人CLI权限与网页URL能力另见 `docs/NETEASE_RESEARCH.md`；没有平台播放权限时不截获CLI流、不解密`.ncm`，可使用用户合法取得的本机普通原神音频。
