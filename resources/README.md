# 个人本地资源

原神音频建议存放于 `resources/local/audio/genshin/`，本机已创建该目录。`resources/local/` 全部被 Git 忽略；原神音频不进入 public、仓库或网站发行包。

先准备一张专辑中的几首曲目即可，不需要一次下载全 OST。使用自己可合法获取并用于个人播放的 MP3、FLAC、WAV，也可按浏览器支持情况使用 OGG/M4A。MVP 不支持 `.ncm`，不实现音乐平台登录、爬取、签名接口或加密格式解码。

该目录是整理位置，不是网页自动读取路径。浏览器通过用户文件选择导入；优先支持普通多文件选择，目录选择作为增强。文件的标题、专辑、盘号/轨号用于候选匹配；不从文件名推定作曲家或地点。候选匹配仍需核实，同名、翻译和剪辑版保留不确定性。

页面内本地文件使用 object URL；刷新后不把旧 URL 当作可用音源。MVP 持久化收藏、播放列表、简介和文件匹配信息；若未缓存音频内容，刷新后明确要求重新选择文件。大规模全 OST 不默认复制到浏览器存储；File System Access 的文件夹句柄及权限恢复列为后续增强。

已存在的 `public/audio/demo/` 仅含独立核实 CC BY 4.0 的非原神许可示例，见该目录署名文件。两类音源必须在界面明确区分。
